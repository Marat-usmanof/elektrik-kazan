# Обновление сайта elektrik-kazan

В архиве:
- `script.js` — улучшенный калькулятор, WhatsApp, печатная/PDF-смета и галерея.
- `light-redesign.css` — светлая тема и адаптивные стили.
- `robots.txt` и `sitemap.xml` — базовая SEO-настройка.

## Как установить
1. В GitHub открой репозиторий `Marat-usmanof/elektrik-kazan`.
2. Замени содержимое `script.js` файлом из архива.
3. Загрузи `light-redesign.css` в корень репозитория.
4. В `index.html` сразу после строки `<link rel="stylesheet" href="style.css">` добавь:
   `<link rel="stylesheet" href="light-redesign.css">`
5. Загрузи `robots.txt` и `sitemap.xml` в корень.
6. В `prices.js` найди строку `["Минимальный заказ (выезд)","шт.",2400]` и замени `2400` на `2000`.
7. В `index.html` исправь `от 140 ₽/м²` на `от 170 ₽/м²`, если такая строка ещё есть.
8. Сохрани изменения. GitHub Pages обновит сайт автоматически.

Номер для WhatsApp в калькуляторе: +7 (952) 038-37-77. Проверь, что этот номер верный и на нём активен WhatsApp.
